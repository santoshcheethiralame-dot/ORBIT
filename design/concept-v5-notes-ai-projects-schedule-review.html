Deadlocks

Overview

A deadlock is a state where a set of processes are each blocked, waiting on a resource held by another process in the same set — so none can ever proceed.

Four Coffman Conditions (all must hold)

  • ▸Mutual exclusion — resource held in non-shareable mode
  • ▸Hold & wait — holds ≥1 resource while requesting more
  • ▸No preemption — resources released only voluntarily
  • ▸Circular wait — closed chain, each waiting on the next

Banker's Algorithm

Grant a request only if the resulting state is safe — there exists a sequence in which every process can still finish.

Need[i] = Max[i] − Allocation[i]

Common Mistakes

  • ×Confusing deadlock with starvation — starvation is indefinite postponement, not mutual blocking.
  • ×Assuming detection alone resolves it — you still need a recovery step.
